# ChatPy

## Coded in Python

### A highly-secure End-to-End encrypted Chat App.

#### Features:
1. End-to-End Encrypted
2. Encrypted Chat Storing Features
3. Uses Cryptographic Algorithms for Encryption
4. Efficient Error-handling
5. Multi-room functionality
6. Special permissions for the Room Admin
7. Locked with Special Master Password (setupped by User)

#### How to use it?

1. Run the server.exe and client.exe (execution) files at a time - make sure to keep server.exe running in background.
2. Setup the Master Password (only applicable if its your first time using the app).
3. Re-enter the Master Password for confirmation.
4. Enter Master Password again for login in.
5. Choose a username.
6. Enter the room name to Join/Select
7. Enter the room password (Users can only chat if the room name and password matches on both ends)
8. Chat :)
